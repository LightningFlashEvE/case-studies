# 技术选型：快速调试与设备边界

| 决策 | 方案比较 | 本案例的方向与代价 |
|---|---|---|
| 调试界面 | 脚本命令行与桌面 GUI | Tkinter 便于集中参数和读数；串口阻塞不能影响交互响应 |
| 设备通信 | 为一种协议定制与协议适配 | 项目说明支持两类串行协议；切换时仍需验证单位、位置语义和停止行为 |
| 反馈策略 | 仅按时间运行与读取重量后判断 | 利用重量反馈作出停止决策；天平延迟和落料滞后仍影响最终结果 |
| 调试范围 | 每次整机联动与分离天平测试 | 独立读数测试有助于定位通信及解析问题；无法证明真实电机联动通过 |
| 配置方式 | 固定参数与外部配置 | 外部配置方便换设备；需要防止遗留参数在新设备上被误用 |
| 结果记录 | 仅观察界面与持久化测试记录 | 日志和表格便于追溯；真实设备参数与实验结果不应直接公开 |

这里没有比较不同设备或算法的实测精度。后续评价需要控制物料、环境和采样条件，并区分过程误差与测量误差。
